# student-attendance-monitoring-system
This is a digital attendance tracking system developed for the College of Social Sciences and Humanities (CSSH) at Mindanao State University-Main Campus. The system replaces slow, traditional paper-based attendance sheet methods with a fast, reliable, and centralized digital platform to track student attendance and reduce errors.
**Project Name:** Student Attendance Monitoring System for MSU-CSSH

**Type:** Application Development & Information System Project

**Project Description:** This is a digital attendance tracking system developed for the College of Social Sciences and Humanities (CSSH) at Mindanao State University-Main Campus. The system replaces slow, traditional paper-based attendance sheet methods with a fast, reliable, and centralized digital platform to track student attendance and reduce errors.

**My Role & Contributions:**
1. Collaborated on designing and building the system's core functionalities (like login and attendance recording).
2. Assisted in testing the system on a live server to ensure accuracy and security for students and faculty.
3. Worked on the documentation, user testing, and project final reports.
